CLASS SIX PAPER — FREE WEBSITE STARTER

Files:
- index.html : Complete starter website.

How to use:
1. Extract the ZIP file.
2. Open index.html in Chrome to preview it.
3. To publish it for free, use GitHub Pages:
   - Create/sign in to a GitHub account.
   - Create a new public repository named class-six-paper.
   - Upload index.html.
   - In repository Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.
   - GitHub will show the public website address after publishing.

Note:
- This is a starter website with practice/sample questions, not official board papers.
- The “Print / Save PDF” button lets visitors print or save the currently open paper as PDF from their browser.
- To add real downloadable PDF files, upload those PDFs to the repository and add links to them in index.html.
